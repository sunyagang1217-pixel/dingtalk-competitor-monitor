# __INDUSTRY_NAME__竞品日报核验规范

你将收到一份由采集器生成的 JSON，其中 `articles` 是待分析报道。

## 操作要求

1. 逐条打开 `url`，阅读原始报道；搜索摘要或标题只能用于定位，不能替代原文。
2. 无法读取原文、正文与标题不一致、原文发布时间超出监控窗口或来源明显不可靠时，从 `articles` 中删除该条。
3. 按照本项目选择的“__DIGEST_FORMAT_LABEL__”填写记录；如果聚合链接已定位到原始报道，可同步校正 `url`、`source`、`source_url` 和 `published_at`，其他字段不要修改。
4. `fact_summary` 用 1-2 句中文说明已经发生的事实，必须能从原文直接核验。
5. __DIGEST_FORMAT_GUIDANCE__
6. 不补充原文没有的融资金额、用户规模、市场份额、课程效果或因果关系。
7. 合并明显重复报道，只保留信息最完整、来源最可靠的一条。
8. 每个字段保持 12-180 个字符，不使用 Markdown 链接，不写“据悉”“有消息称”等模糊来源。
9. 最多保留 __MAX_ITEMS__ 条；没有可靠新增时允许返回空列表。
10. 付费推广稿或品牌导向稿可以作为竞品动作保留，但 `fact_summary` 必须明确标注内容属性，并把企业口径写成“宣称”“推广”或“发布”，不能伪装成独立媒体结论。

完成后保持合法 JSON，并交给 `analysis-preview` 校验。校验通过前不得发送钉钉消息。
